# Задание для Codex: подключить спрайты персонажа

Используй содержимое каталога `hooded_step_game_sprites/` (распаковано из одноимённого архива) и добавь анимации текущему персонажу в этой игре.

1. Определи используемый движок и текущие места загрузки ассетов / управления анимациями. Сохрани существующую механику движения и scale персонажа.
2. Подключи прозрачный RGBA-атлас `sprite_sheet.png` размером 1280×2432, сетка 4 колонки × 4 строки, 13 используемых кадров по 320×608. Для Phaser 3 также есть `atlas_phaser.json`; для других движков используй `animations.json`.
3. Реализуй клипы `idle`, `step_left`, `step_right` и `side_to_side` согласно полю `animations` из `animations.json`. Применяй **индивидуальные** `duration_ms` каждого кадра, а не общий FPS, чтобы короткий шаг и паузы оставались естественными.
4. Стойки в конце шагов — **frame_03** (влево) и **frame_09** (вправо): у персонажа обе ноги стоят ровно. Кадры с отставленной ногой — только переходные, их нельзя использовать как остановку.
5. Для всех кадров выставь одинаковую точку привязки x=0.5, y=0.9671, используй одинаковое визуальное масштабирование и глубину отрисовки; без подрезки отдельных кадров, чтобы не возникло дрожания.
6. Спрайты уже слегка смещены внутри ячеек. Не прибавляй `shift_x_px` к позиции игрового объекта. Реальное перемещение персонажа по сцене — отдельно через текущую игровую механику.
7. Сохрани чёрную пустоту под капюшоном; не добавляй лицо и фон. Протестируй переходы влево/вправо и looping, чтобы не было рывков или зависаний с вытянутой ногой.
8. Перечисли изменённые файлы и команды локальной проверки.

Сначала прочитай `README.md` и `animations.json`.
